# Pong для терминала

Игра на C: один игрок против компьютера или два игрока за одной клавиатурой.
Матч идёт до 7 очков. Отскок зависит от места попадания в ракетку;
после каждого удара мяч ускоряется.

## Запуск на macOS

Откройте приложение **Терминал**. Понадобятся компилятор C и `make` из
Xcode Command Line Tools. Если они ещё не установлены, выполните:

```sh
xcode-select --install
```

Завершите установку в открывшемся окне. Склонируйте репозиторий и соберите игру:

```sh
git clone https://github.com/PashchinkoAO/my-first-repo.git
cd my-first-repo
make
./pong
```

Для игры вдвоём:

```sh
./pong --two-players
```

Без `make` игру можно собрать одной командой:

```sh
cc -std=c11 -O2 -Wall -Wextra -Wpedantic pong.c -o pong
./pong
```

Внешние библиотеки и Homebrew не нужны. Используются стандартная библиотека C,
POSIX API и управляющие последовательности ANSI, доступные в Terminal и iTerm2.
Те же команды сборки подходят для Linux. Требуется окно хотя бы **60 × 20**
символов; обычное окно 80 × 24 подходит.

## Управление

| Клавиши | Действие |
| --- | --- |
| `W` / `S` | Левая ракетка вверх / вниз |
| `↑` / `↓` | Правая ракетка в игре вдвоём; левая в игре против компьютера |
| `Пробел` | Пауза / продолжение |
| `R` | Новый матч |
| `Q` или `Ctrl+C` | Выход |

Нажимайте или удерживайте клавиши движения; удержание использует автоповтор
терминала. Для `W`, `S`, `R`, `Q` переключитесь на английскую раскладку.
При слишком маленьком окне игра ждёт его увеличения. При изменении размеров
поля начинается новая подача, счёт сохраняется.

При выходе восстанавливаются настройки терминала и видимость курсора.
`Ctrl+Z` приостанавливает процесс и возвращает терминал; `fg` продолжает игру.

Справка: `./pong --help`. Удалить собранную программу: `make clean`.
