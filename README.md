# Пошаговый Pong — School 21

Игра для двух игроков по заданию. Весь код находится в `src/pong.c`.
Используются только `stdio.h`, целые числа, условия, циклы и функции.
В коде нет массивов, указателей, структур, динамической памяти и изменяемых
глобальных переменных. `#define` задаёт четыре числовые константы.

## Соответствие заданию

- Поле — **80 столбцов × 25 строк, включая рамку**. Счёт и подсказка находятся вне поля.
- Каждая ракетка состоит из **3** символов `|`, мяч — из **1** символа `O`.
- Первый игрок управляет клавишами **A/Z**, второй — **K/M**.
- **Пробел** пропускает движение ракетки, но делает один шаг мяча.
- Один корректный ввод — один шаг игры и новая отрисовка.
- Побеждает первый, кто набрал **21 очко**. Программа поздравляет победителя и завершается.
- В программе нет `system()`, запуска внешних команд, POSIX API и сторонних библиотек.

## Сборка и запуск на macOS

Откройте Терминал. Если компилятор ещё не установлен, выполните
`xcode-select --install` и завершите установку в открывшемся окне.

```sh
git clone https://github.com/PashchinkoAO/my-first-repo.git
cd my-first-repo
make
./pong
```

Если репозиторий уже склонирован, в его папке выполните `git pull`, затем `make` и `./pong`.

Сборка без Makefile:

```sh
cc -std=c11 -Wall -Wextra -Werror -Wpedantic src/pong.c -o pong
./pong
```

Эти команды подходят и для Linux. Для отображения всего кадра увеличьте окно
терминала хотя бы до 80 столбцов и 29 строк. `make clean` удаляет собранную программу.

## Как играть

Используйте английскую раскладку. Введите **ровно один символ и нажмите Enter**:

| Ввод | Действие |
| --- | --- |
| `a` или `A` | Левая ракетка вверх |
| `z` или `Z` | Левая ракетка вниз |
| `k` или `K` | Правая ракетка вверх |
| `m` или `M` | Правая ракетка вниз |
| Один пробел | Пропустить движение ракеток |

Enter нужен потому, что обычный терминал передаёт строку программе после нажатия
Enter. Это позволяет использовать стандартную функцию `getchar()` без настройки терминала.

Пустая строка, неизвестный символ и несколько символов в одной строке не делают
ход: программа просит повторить ввод. У края поля ракетка остаётся на месте,
но правильная команда всё равно продвигает мяч на один шаг.
Чтобы завершить незаконченный матч, нажмите Ctrl+D в пустой строке — это конец ввода (`EOF`).

Каждый кадр печатается ниже предыдущего. Очистка экрана и управляющие
последовательности терминала не используются.

## Как устроен код

`main()` хранит координаты, направления и счёт. Сначала выводится начальное поле,
затем цикл повторяет четыре действия: читает команду, двигает ракетку,
двигает мяч с учётом отскоков и печатает новое поле. Цикл заканчивается при 21 очке
или конце ввода.

| Функция | Назначение |
| --- | --- |
| `draw_field()` | Два вложенных цикла печатают поле по строкам и столбцам |
| `read_command()` | Читает строку, проверяет единственный символ и возвращает правильную команду либо `EOF` |
| `move_paddle()` | Возвращает новую верхнюю координату ракетки с учётом границ |
| `bounce_vertical()` | Меняет вертикальное направление мяча перед верхней или нижней стенкой |
| `bounce_horizontal()` | Меняет горизонтальное направление мяча перед ракеткой |

Координата `x` растёт вправо, `y` — вниз. Нумерация начинается с нуля:
столбцы — от 0 до 79, строки — от 0 до 24. Крайние строки и столбцы образуют рамку.
Левая ракетка находится в столбце 2, правая — в столбце 77.
`left_y` и `right_y` — верхние клетки ракеток; они могут быть от 1 до 21.

`dx` и `dy` равны `1` или `-1`: они показывают направление движения мяча.
За ход к `ball_x` прибавляется `dx`, к `ball_y` — `dy`.
Перед движением проверяется следующая клетка. Если она занята стенкой или
ракеткой, соответствующее направление меняет знак. Сначала проверяется
вертикальный отскок, затем попадание в ракетку с учётом новой вертикальной координаты.

Если мяч проходит за ракетку и достигает столбца 1 или 78, очко получает
противоположный игрок. Мяч возвращается в центр, вертикальное направление
снова становится `1`, а горизонтальное сохраняется: подача идёт в сторону
игрока, пропустившего мяч. Ракетки остаются на своих местах.

Результат `getchar()` хранится в `int`, поскольку эта функция возвращает
не только код символа, но и специальное значение `EOF`.
